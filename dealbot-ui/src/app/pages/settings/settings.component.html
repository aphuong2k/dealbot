📌 Cách lấy Cookie Facebook nhanh nhất:
  1. Cài tiện ích Cookie-Editor trên trình duyệt Chrome / Edge / Cốc Cốc.
  2. Đăng nhập nick Facebook tương ứng (ví dụ nick phụ phụ trách nhóm).
  3. Mở Cookie-Editor trên tab Facebook, bấm Export ➔ chọn Export as JSON.
  4. Dán nội dung vừa copy vào ô trên rồi bấm "💾 Lưu & Cập Nhật Cookie".
